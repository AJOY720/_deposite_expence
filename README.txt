জমা-খরচ Android PWA — সংস্করণ 2

নতুন ফিচার:
- হিসাব Edit ও Delete
- মাসিক রিপোর্ট এবং বার্ষিক রিপোর্ট
- রিপোর্টের মোট জমা, মোট খরচ, নিট ফলাফল
- PIN/পাসওয়ার্ড প্রথমবার সেট করা, আনলক এবং পরিবর্তন
- সব হিসাব বা নির্বাচিত রিপোর্ট CSV হিসেবে ডাউনলোড
- সার্চ, মাস/ধরন ফিল্টার, Local Storage, PWA offline cache

Android-এ GitHub Pages দিয়ে চালানোর ধাপ:
1. ZIP ফাইল ডাউনলোড করে Extract করুন।
2. github.com-এ লগইন করে New repository তৈরি করুন (যেমন joma-khoroch)। Public repository সহজ।
3. Repository-তে Add file → Upload files নির্বাচন করে এই ZIP-এর ভেতরের ফাইলগুলো আপলোড করুন: index.html, style.css, app.js, manifest.json, sw.js। README-ও চাইলে আপলোড করুন। ZIP-কে নিজে ZIP হিসেবেই আপলোড করবেন না; Extract করা ফাইল আপলোড করবেন।
4. Commit changes চাপুন।
5. Repository Settings → Pages-এ যান।
6. Build and deployment-এ Deploy from a branch নির্বাচন করুন; Branch: main এবং Folder: / (root) সেট করে Save করুন।
7. প্রকাশিত HTTPS URL (যেমন https://USERNAME.github.io/joma-khoroch/) তৈরি হলে Android Chrome-এ খুলুন।
8. প্রথমবার একটি PIN/পাসওয়ার্ড সেট করুন। এরপর অ্যাপ খোলার সময় সেটি দিয়ে আনলক করুন।
9. Chrome-এর ⋮ মেনু → Add to Home screen / Install app চাপুন।

Edit/Delete:
- হিসাবের নিচে Edit চাপলে ফর্মে তথ্য আসবে। বদলে “পরিবর্তন সেভ করুন” চাপুন।
- মুছতে “মুছুন” চাপুন এবং নিশ্চিত করুন।

মাসিক/বার্ষিক রিপোর্ট:
- রিপোর্ট অংশে ধরন বেছে মাস বা বছর নির্বাচন করুন।
- “এই রিপোর্ট CSV ডাউনলোড” চাপলে ওই সময়ের লেনদেন Excel-এ খোলার উপযোগী CSV হিসেবে নামবে।

PIN নিরাপত্তা সম্পর্কে গুরুত্বপূর্ণ:
- PIN-এর SHA-256 hash Local Storage-এ রাখা হয়, কিন্তু লেনদেনের ডেটা এনক্রিপ্ট করা নয়।
- এটি সাধারণ অ্যাপ-লক; উচ্চ-নিরাপত্তার vault বা সার্ভার-ভিত্তিক নিরাপত্তা নয়।
- একই ব্রাউজার/ডিভাইসে ডেটা থাকে। Browser data clear করলে হিসাব এবং PIN মুছে যেতে পারে।
- নিয়মিত CSV ব্যাকআপ রাখুন। অন্যের সঙ্গে শেয়ার করা ডিভাইসে সংবেদনশীল তথ্য রাখবেন না।
- PIN ভুলে গেলে অ্যাপের ভেতর থেকে পুনরুদ্ধার ব্যবস্থা নেই। ডেটা না মুছে PIN রিসেট করার আগে ব্যাকআপ নিশ্চিত করুন।

বিদ্যমান v1 ডেটা:
- v1-এর ডেটা আলাদা localStorage key-তে ছিল। এই v2 স্বয়ংক্রিয়ভাবে পুরনো ডেটা আমদানি করে না। পুরনো সংস্করণে CSV ডাউনলোড করে নতুন অ্যাপে পুনরায় এন্ট্রি/আমদানি করুন; এই সংস্করণে CSV import UI অন্তর্ভুক্ত নয়।
